# 사이트 설계도(PRD) — 아해교육포럼 공구 파트너 모집

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
아해교육포럼의 영유아 교육제품을 보고, 공동구매·인플루언서가 "이 제품을 팔고 싶다"는 판매 희망을 남기는 사이트.

## 2. 손님
- 누가: 공동구매를 여는 인플루언서 (육아 인스타·블로그·맘카페 등)
- 어디서 알고 오나:
  - 회사가 직접 보내 주는 사이트 주소(URL)
  - 검색
  - 지인·다른 인플루언서의 소개

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 공구가·수익(마진) — 사이트에는 숫자를 적지 않고 "판매 희망을 남기시면 따로 안내해 드려요"로 쓴다
2. 제품 상세·사용 연령 — 어떤 제품이고 몇 살 아이에게 맞는지
3. 진행 방식 — 배송·CS는 누가 하는지, 샘플을 주는지, 최소 수량은 몇 개인지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 제품 사진·영상 (회사 보유 자료 사용)
- 안전 인증 (KC 등) — 인증 번호·종류는 회사 자료 그대로 적는다 (미정)
- 이전 공구 실적·후기 — 실제 자료만 넣는다. 숫자·문구는 지어내지 않는다 (내용 미정)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 판매 희망 남기기
- 누르면: 판매 희망 신청 폼

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + [판매 희망 남기기] 버튼
2. 제품 소개 — 제품 사진·영상, 제품별 사용 연령
3. 믿을 수 있는 이유 — 안전 인증(KC 등), 이전 공구 실적
4. 진행 방식 — 신청부터 공구 오픈까지 순서, 배송·CS·샘플·최소 수량 (내용 미정)
5. 공구 후기 자리 (실제 후기만, 없으면 비워 둠)
6. 판매 희망 신청 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 활동 채널 주소 (인스타·블로그·카페 링크)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 공구가·마진은 비공개 — 사이트에 적지 않는다
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 공구가·마진 숫자 공개
- 회원가입·로그인 (다음에)
- 결제
- 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 아이에게 자신 있게 권할 교육제품, 함께 팔아 주실 파트너를 찾습니다.
2. 아해교육포럼의 영유아 교육제품으로 공동구매를 열어 보세요.
3. 엄마들이 믿고 사는 교육제품, 당신의 채널에서 소개해 주세요.

## 11. 다음에 할 것
- 인플루언서 회원가입·로그인 (회원만 상세 조건 보기). 할 때는 개인정보 처리방침이 따로 필요하다
- 담당자 연락처, 진행 방식 세부 내용(배송·CS·샘플·최소 수량) 채우기
- KC 인증 정보, 이전 공구 실적·후기 실제 자료 넣기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 판매 희망 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
